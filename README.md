# judgment-aware-agent

A vocabulary anchor for **judgment-aware agents** — systems that distinguish between **current judgment** and **stale opinion** in their persistent memory, and refuse to silently overwrite stable user judgment via auto-mutation.

The opposite of memory-as-bag-of-text: memory as a structured substrate where judgment integrity is a first-class invariant.

This name refers to a position outlined in detail at:

- [coevolution-kernel](https://github.com/hegu-1/coevolution-kernel) — main thesis
- [claude-cognition-skills](https://github.com/hegu-1/claude-cognition-skills) — reference implementation

This repository is a vocabulary anchor; the substantive content is in the linked thesis and implementation.
